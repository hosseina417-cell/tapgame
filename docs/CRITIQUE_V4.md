## ایرادات باقی‌مانده (برای V5 — سخت‌سازی نهایی)

1. **اعلان بدون بررسی نتیجه مجوز**: `requestPermission()` آتش‌وفراموش است؛ اگر کاربر رد کند، هر اسکن دوباره درخواست می‌دهد. باید بعد از رد، دیگر درخواست ندهد (پرچم «رد شده»).
2. **اسکنر: هشدار «آماده‌باش» (watch) اعلان نمی‌گیرد** — درست است، ولی در لیست با پامپ/دامپ واقعی مخلوط می‌شود. باید بخش «آماده‌باش» جدا شود.
3. **جزئیات: خطای یک تایم‌فریم کل صفحه را تحت‌الشعاع قرار می‌دهد** — اگر 4h/1d خطا بدهند اما 15m/1h درست باشند، پنل‌ها باید با داده موجود کار کنند (الان می‌کنند ✓ ولی جای بهبود جزئی هست).
4. **`runScan` با ۲۴ سکه و ۶ منبع، در شبکه کند همچنان سنگین است** — باید حداکثر زمان هر سکه محدود شود (مثلاً فقط بایننس+بای‌بیت در اسکنر).
5. **آزمون نهایی روی دستگاه واقعی انجام نشده**: APK فقط ایستایی (badging/signature) بررسی شده. باید حداقل یک بار نصب/اجرا روی اندروید واقعی یا امولاتور تست شود — در این محیط ممکن نیست؛ در README ذکر شود.
6. **`versionName` و «درباره» هم‌خوان نیستند** (هردو 1.0.0 هستند ولی از دو جا می‌آیند) — باید از یک منبع واحد بیایند.
7. **جزئیات جزئی**: در تنظیمات، حذف سکه سفارشی وجود ندارد (فقط افزودن). باید با ✕ قابل حذف باشد.
8. **فونت Vazirmatn سه وزن (۴ فایل) = ~۴۹۰KB در APK** — وزن Bold و Medium تکراری‌اند؛ یک وزن کافی است (بهینه‌سازی حجم).
9. **کد `statCell` از id استفاده می‌کند که اگر برچسب تکراری شود کرش می‌کند** — id ها یکتا هستند ولی بهتر بود کلاس.

## جمع‌بندی

V4 محصولی قابل ارائه است: نمودار تعاملی، اعلان پامپ، سکه سفارشی و مستندات کامل. V5 فقط باید **سخت‌سازی** کند: حذف حاشیه‌ها، تک‌منبع‌کردن نسخه، جداسازی آماده‌باش‌ها، و بازبینی نهایی کل کد — سپس ساخت APK نهایی و تحویل.
