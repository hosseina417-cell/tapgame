## ایرادات باقی‌مانده (برای V3)

1. **درصد احتمال هنوز کالیبره نیست (C6 باز)**: برچسب «آزمایشی» اضافه شد اما می‌توان بهتر کرد: محاسبه «دقت تجربی» روی همان داده‌های تاریخی هر سکه (بکتست سبک سمت کاربر) و نمایش «از N سیگنال اخیر، M٪ موفق». این عدد واقعی است، نه تبدیل tanh.
2. **دکمه بازگشت اندروید کار نمی‌کند**: برنامه SPA بدون تاریخچه است؛ `web.canGoBack()` همیشه false است. کاربر از جزئیات باید دکمه روی صفحه را بزند. نیاز به مسیریابی hash.
3. **رفرش بازار کل لیست را از نو می‌سازد**: جای اسکرول و متن جستجو را از بین می‌برد. باید ردیف‌ها درجا به‌روز شوند.
4. **زنجیره fallback ترتیبی است**: ۶ منبع × ۸ ثانیه = بدترین حالت ۴۸ ثانیه برای یک سکه. باید منابع سریع اول به صورت موازی (race) امتحان شوند.
5. **اسکنر: هشدارهای تکراری**: «آماده‌باش» هر اسکن تکرار می‌شود. باید dedupe با زمان خنک‌کننده.
6. **جزئیات سکه**: ارزش بازار/رتبه و تغییر ۱ ساعته/۲۴ ساعته نمایش داده نمی‌شود.
7. **کد مرده**: `fmtDuration` و `esc` استفاده نشده‌اند؛ صف اسکن با `setInterval` چک می‌شود (باید Promise داشته باشد).
8. **`getTicker24h` بدون محافظ**: اگر خارج از try خطا بدهد، unhandled rejection.
9. **مستندات**: README فارسی هنوز وجود ندارد.
10. **پوشش تست**: سناریوی «آفلاین → fallback به کش» تست نشده.

- هم‌ترازی EMA در نمودار با تست واحد اثبات شد.
- لغو درخواست با AbortController — درست.
