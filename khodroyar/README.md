# 🚗 خط ریورک مانیان خودرو (ManianKhodro)

<div dir="rtl">

دستیار ثبت و پیگیری **ایرادات خودرو** — شامل روش تعمیر، ابزار و قطعات مورد نیاز و هزینه‌ها.
کاملاً **آفلاین**، با رابط فارسی راست‌به‌چپ و تاریخ **شمسی**.

</div>

## ✨ امکانات
- ثبت خطا/ایراد خودرو با: علائم، توضیحات، **کد OBD-II**، سطح اهمیت (کم/متوسط/زیاد/بحرانی)
- **روش تعمیر** قدم‌به‌قدم + **ابزار مورد نیاز** (با افزودن سریع آچار فرانسه، جک، دیاگ و…) + **قطعات لازم**
- پیگیری وضعیت: جدید ← در حال بررسی ← در حال تعمیر ← تعمیرشده (با تاریخ تعمیر شمسی)
- 💰 ثبت هزینه + **داشبورد آمار** (تعداد باز، تعمیرشده، مجموع هزینه)
- 🔍 جست‌وجوی هوشمند (نادیده‌گرفتن ي/ی و ك/ک و ارقام فارسی/لاتین)
- 💾 **پشتیبان‌گیری/بازیابی JSON** (بدون نیاز به هیچ مجوزی — از طریق فایل‌های سیستم)
- 📤 اشتراک‌گذاری گزارش کامل خطا به‌صورت متن
- تاریخ شمسی + ارقام فارسی + RTL کامل + پشتیبانی انگلیسی

## 📱 نصب
فایل `khodroyar/dist/KhodroYar-v5.0.0.apk` را روی گوشی اندرویدی (حداقل Android 5.0 / API 21) منتقل و نصب کنید.

## 🔨 ساخت از صفر (بدون Android Studio!)
خط تولید این پروژه به Android SDK رسمی، Gradle یا Android Studio نیاز ندارد.
پیش‌نیازها فقط: `python3`، `pip`، `git`، `zip`، `curl`.

```bash
# 1) نصب ابزار (JDK از PyPI، build-tools و android.jar از میرورهای GitHub)
khodroyar/tools/setup_env.sh

# 2) اجرای تست‌های منطقی (تاریخ شمسی، اعداد، نرمال‌سازی)
khodroyar/tools/run_tests.sh

# 3) بیلد APK امضاشده
cd khodroyar && ./build_apk.sh
# خروجی: dist/KhodroYar-v<version>.apk   (نسخه از version.properties)
```

جزئیات خط تولید: [docs/BUILD.md](docs/BUILD.md)

## 🧪 تست
```bash
./tools/run_tests.sh   # ۲۵ تست JVM: تبدیل تاریخ، قالب‌بندی اعداد، نرمال‌سازی متن
```

## 🗂 ساختار
```
khodroyar/
├── AndroidManifest.xml
├── src/com/khodroyar/app/
│   ├── data/        # مدل داده، دیتابیس SQLite، اجراگر پس‌زمینه، پشتیبان JSON
│   ├── ui/          # MainActivity (لیست/جست‌وجو/آمار)، ویرایش، جزئیات
│   └── util/        # تاریخ شمسی، قالب‌بندی فارسی
├── res/             # لی‌آوت‌ها، استایل‌ها، آیکون تطبیقی، دو زبانه fa/en
├── tools/           # setup_env.sh، run_tests.sh
├── build_apk.sh     # خط تولید: aapt2 → kotlinc → d8 → zipalign → apksigner
└── docs/            # نقد نسخه‌ها و مستندات ساخت
```
