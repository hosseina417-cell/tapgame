# ⚡ آربیتراژ پرو — نسخه ۵.۰

اپلیکیشن اندرویدی پایش و معاملهٔ آربیتراژ بین صرافی‌های رمزارز داخل ایران (Python/Kivy).

## صرافی‌ها
| صرافی | پایش قیمت | معاملهٔ خودکار |
|---|---|---|
| نوبیتکس | ✅ | ✅ |
| والکس | ✅ | ✅ |
| بیت‌پین | ✅ | — |
| رمزینکس | ✅ | — |

ارزها: `USDT` `BTC` `ETH` `TRX` `DOGE` (همه در برابر تومان)

## قابلیت‌ها
- محاسبهٔ سود با **VWAP عمقی** دفتر سفارش به‌اندازهٔ بودجهٔ شما (نه فقط سطح اول)
- نرمال‌سازی خودکار ریال/تومان + پالایش دیتای فاسد با میانهٔ بین‌صرافی
- کسر کارمزد هر دو سمت + حاشیهٔ لغزش
- موتور ریسک: حداقل سود، سقف معاملات روزانه، cooldown، سقف کهنگی دیتا
- حالت تمرینی (Paper) به‌صورت پیش‌فرض — بدون پول واقعی
- معاملهٔ خودکار اختیاری با تأییدیهٔ صریح + کلید توقف فوری (Kill Switch)
- تاریخچهٔ ماندگار معاملات + هشدار فرصت (نوتیفیکیشن اندروید)
- رابط کاربری کاملاً فارسی با فونت وزیرمتن و شکل‌دهی RTL

## ساختار کد
```
main.py        رابط کاربری (Kivy)
core.py        شبکه + مدل دفتر سفارش
exchanges.py   کانکتورهای ۴ صرافی
engine.py      موتور آربیتراژ (VWAP، sanity check، ریسک)
monitor.py     پایشگر پس‌زمینه
trader.py      اجرای معامله (تمرینی/واقعی)
store.py       تنظیمات، کلیدها، تاریخچه
```

## ساخت APK
GitHub Actions با buildozer به‌صورت خودکار APK می‌سازد (آرتیفکت `tapgame-apk`).
ساخت محلی:
```bash
pip install buildozer cython==0.29.36
buildozer android debug
# خروجی: bin/*.apk
```

## اجرای دسکتاپ (تست)
```bash
pip install kivy==2.3.0 arabic_reshaper python-bidi certifi
python main.py
```

## ⚠️ سلب مسئولیت
معاملهٔ رمزارز و آربیتراژ دارای ریسک مالی است. این نرم‌افزار «همان‌طور که هست» ارائه می‌شود و مسئولیت هر سود یا زیان با کاربر است. پیش از فعال‌کردن حالت واقعی، مدت کافی در حالت تمرینی تست کنید و دسترسی «برداشت» کلید API را در پنل صرافی غیرفعال کنید.
