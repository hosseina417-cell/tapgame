# نبض کریپتو ۷ — اسکنر چندمنبعی با هوش مصنوعی محلی

اپلیکیشن Native Android برای اسکن بازارهای Spot/USDT، جمع‌بندی سیگنال‌های تکنیکال خرید/فروش، تشخیص حرکت‌های پامپی/دامپی احتمالی و تحلیل زمان‌محور با **مدل یادگیری ماشین روی دستگاه**.

> ابزار آموزشی است، توصیهٔ مالی نیست و هیچ معامله‌ای اجرا نمی‌کند. درصد خروجی مدل احتمال سود یا تضمین جهت قیمت نیست.

## هوش مصنوعی نسخهٔ ۷

- مدل supervised رگرسیون لجستیک برای هر بازار، بدون مدل ابری یا API key
- آموزش جداگانه روی کندل‌های بسته‌شدهٔ همان ارز و همان گوشی
- ویژگی‌های بازده کوتاه‌مدت، روند، نوسان، حجم و ساختار کندل
- پیش‌بینی جهت آماری افق تقریبی ۱۵ دقیقه
- جداسازی زمانی train/validation و purge مرز برای کاهش نشت آینده
- سنجش دقت متوازن و Brier روی نمونه‌های جدیدترِ دیده‌نشده
- رد خودکار مدل فاقد هر دو کلاس، دادهٔ کافی یا کیفیت آزمون
- رأی محدود AI بین `-12..+12`؛ تحلیل تکنیکال و هشدار پامپ/دامپ کنترل اصلی را حفظ می‌کنند
- نمایش خروجی مدل، اعتبار فعلی، تعداد نمونه و نتیجهٔ آزمون برای شفافیت
- تمام آموزش و inference محلی است؛ کندل‌ها به سرویس AI ارسال نمی‌شوند

## سایر قابلیت‌ها

- پشتیبانی از صدها نماد USDT و تحلیل هم‌زمان ۴۰، ۸۰ یا ۱۲۰ بازار
- افزودن هر نماد دلخواه به اسکن و منتخب‌ها با گزینهٔ «＋ تحلیل»
- تجمیع تیکر از **Binance، KuCoin، Bybit و OKX**
- قیمت اجماعی مقاوم، حجم تجمیعی، حذف قیمت پرت و نمایش اختلاف منابع
- غنی‌سازی اختیاری رتبه و ارزش بازار با API عمومی **CoinGecko**
- انتخاب خودکار نقدشونده‌ترین صرافی و failover کندل‌های ۵ و ۱۵ دقیقه
- EMA ۹/۲۱/۵۰، RSI ۱۴، MACD، ATR و ناهنجاری Median/MAD
- لمس کارت برای بازکردن نماد در **TradingView**
- لینک رسمی TradingView، CoinMarketCap، CoinGecko و Google در جزئیات
- رابط فارسی RTL، cache محلی، بدون حساب یا مجوز معامله

## سیاست منابع

CoinMarketCap برای API رسمی به کلید اختصاصی نیاز دارد و Google و TradingView فید عمومی مجاز برای بازتوزیع قیمت ارائه نمی‌کنند. برنامه آن‌ها را اسکرپ نمی‌کند؛ دادهٔ محاسباتی را از APIهای عمومی چهار صرافی و CoinGecko می‌گیرد و صفحات رسمی سه سرویس دیگر را باز می‌کند.

## ساخت و آزمون

```bash
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

خروجی نهایی:

```text
releases/NabzCrypto-7.0.0.apk
```

> گواهی امضای این build نسبت به نسخهٔ ۶ چرخانده شده است. برای نصب روی گوشی دارای نسخهٔ قبلی، ابتدا نسخهٔ قدیمی را حذف و سپس APK نسخهٔ ۷ را نصب کنید.

## معماری

- `analysis/OnDeviceAiAnalyzer`: آموزش، validation زمانی و inference محلی
- `analysis/IndicatorEngine`: موتور ترکیبی AI و اندیکاتورها
- `data/`: HTTP امن، چهار Provider، اجماع قیمت، failover، cache و تنظیمات
- `model/`: مدل‌های immutable بازار، AI و نتیجه
- `ui/`: رابط فارسی، Sparkline و لینک‌های خارجی امن
