# SP2L Pour Samadi Strategy Indicator [V5 FINAL]

## اندیکاتور استراتژی SP2L پور صمدی - نسخه نهایی

اندیکاتور تحلیل بازار کریپتو بر اساس استراتژی **Spike 2 Leg (SP2L)** استاد محمدعلی پورصمدی.

### نحوه استفاده
1. فایل `sp2l_pour_samadi_V5_FINAL.pine` را باز کنید
2. کل محتوای فایل را کپی کنید
3. در TradingView → Pine Editor → Paste → Add to Chart

---

## ویژگی‌های کلیدی

### 🔍 تشخیص اسپایک
- شناسایی خودکار حرکات شارپی بازار
- فیلتر مومنتوم چندسطحی
- فیلتر دوجی (جلوگیری از اسپایک‌های ضعیف)
- تأییدیه حجم

### 📊 FVG (Fair Value Gap)
- تشخیص خودکار گپ‌های ارزش منصفانه
- ۴ نوع فیلتر: All / Significant / Structural / Major
- ادغام خودکار FVG های همپوشان
- عمر مشخص با پاکسازی خودکار

### 🏗️ ساختار بازار
- تشخیص BOS (Break of Structure)
- تشخیص CHoCH (Change of Character)
- شناسایی Order Block
- ردیابی داینامیک Higher Lows / Lower Highs

### 📈 تأییدیه‌ها
- تأیید مولتی تایم‌فریم
- تأیید RSI + واگرایی
- Kill Zone Time Filter
- سیستم امتیازدهی اطمینان (۱۰ عامل)

### 💼 مدیریت پوزیشن
- ۳ حالت ورود: Aggressive / Moderate / Defensive
- ورود دوم (Secondary Entry)
- تریلینگ استاپ خودکار
- نسبت ریسک به ریوارد قابل تنظیم

### 📋 داشبورد
- نمایش وضعیت لحظه‌ای
- P&L آنرئال‌تایم
- آمار: Win Rate, Profit Factor, Max DD
- هشدار ضررهای متوالی
- پیشنهاد ریسک بهینه

## الگوهای ورود

### سیگنال خرید (Bullish SP2L)
1. اسپایک صعودی شناسایی شد (کندل‌های سبز متوالی + FVG)
2. Higher Low ها در حال شکل‌گیری هستند
3. قیمت به سطح HL برمی‌گردد → **ورید خرید**
4. استاپ: زیر منشاء اسپایک
5. تارگت: بر اساس R:R

### سیگنال فروش (Bearish SP2L)
1. اسپایک نزولی شناسایی شد (کندل‌های قرمز متوالی + FVG)
2. Lower High ها در حال شکل‌گیری هستند
3. قیمت به سطح LH برمی‌گردد → **ورود فروش**
4. استاپ: بالای منشاء اسپایک
5. تارگت: بر اساس R:R
