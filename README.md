# 📈 اسکنر کریپتو (Crypto Scanner)

اپلیکیشن اندروید **اسکنر بازار کریپتو**: سیگنال خرید/فروش، تحلیل تکنیکال، درصد احتمال، و تشخیص پامپ و دامپ — با ۷ منبع داده و حالت آفلاین.

> ⚠️ **سلب مسئولیت:** این برنامه فقط یک ابزار تحلیل آموزشی است. سیگنال‌ها و درصدها تخمین‌های آماری ساده هستند و **توصیه مالی نیستند**. بازار رمزارز پرریسک است.

## ✨ امکانات

| قابلیت | توضیح |
|---|---|
| 🏛 فهرست بازار | ۳۲+ سکه محبوب با قیمت زنده، تغییر ۲۴ ساعته، سیگنال سریع، جستجو و نشان‌کردن |
| 📊 تحلیل چندتایم‌فریمی | ۱۵ دقیقه / ۱ ساعت / ۴ ساعت / ۱ روز — RSI, MACD, استوکاستیک, بولینگر, ATR, حجم |
| 🎯 سیگنال خرید/فروش | امتیاز شفاف ۶‌عاملی (روند، مکدی، RSI، استوکاستیک، بولینگر، حجم) + درصد احتمال |
| 📉 بکتست تجربی | نرخ موفقیت واقعی سیگنال‌ها روی داده تاریخی همان سکه (بازده ۴ کندل بعد) |
| 🚨 اسکنر پامپ/دامپ | تشخیص جهش قیمت + جهش حجم (ملایم/شدید/بسیار شدید) با اعلان سیستمی |
| 🔄 ۷ منبع داده | بایننس، بای‌بیت، اوکی‌ایکس، کراکن، کریپتوکامپیر، کوین‌گکو، کوین‌کپ — fallback خودکار و موازی |
| 📴 حالت آفلاین | کش هوشمند داده‌ها + بنر «داده کش‌شده» |
| 📱 نمودار تعاملی | کشیدن افقی برای پیمایش تاریخ، لمس برای قیمت/زمان، دابل‌تپ برای بازنشانی |
| ➕ سکه سفارشی | افزودن هر سکه با نماد (مثل WIF) از جستجوی کوین‌گکو |

## 🏗 معماری

```
app/                     ← اپلیکیشن وب (داخل APK در assets)
  index.html
  css/style.css          ← تم تیره RTL با فونت وزیرمتن
  js/
    util.js              ← قالب‌بندی، DOM، صف محدود با drain
    store.js             ← تنظیمات + کش آفلاین (localStorage، سقف ۱.۵MB)
    indicators.js        ← اندیکاتورها (خالص، بدون DOM — قابل تست)
    strategy.js          ← موتور سیگنال + بکتست تجربی
    pumpdetect.js        ← تشخیص پامپ/دامپ
    providers.js         ← ۷ منبع داده با fallback موازی
    chart.js             ← نمودار کندل‌استیک تعاملی (Canvas)
    ui.js                ← رندر صفحات
    app.js               ← کنترلر: مسیریابی hash، تایمرها، اسکن
android/
  AndroidManifest.xml    ← minSdk 21، targetSdk 34، مجوزهای شبکه/اعلان
  src/.../MainActivity.java ← WebView + پل اعلان سیستمی (AndroidBridge)
tools/
  build_apk.sh           ← ساخت APK در ۶ مرحله
  fetch_toolchain.sh     ← دانلود خودکار ابزار ساخت (از pypi/npm/github)
  test_logic.js          ← ۴۸+ تست واحد (node tools/test_logic.js)
  test_ui_smoke.js       ← تست دود UI با jsdom
  test_offline.js        ← تست حالت آفلاین
docs/CRITIQUE_V*.md      ← گزارش‌های نقد ۵ دوره‌ای
bin/                     ← APK نهایی
```

**مسیریابی:** اپ یک SPA با مسیرهای hash است (`#/market`، `#/coin/btc`، `#/scanner`، `#/settings`)؛ دکمه بازگشت اندروید با تاریخچه WebView کار می‌کند.

**امنیت WebView:** دسترسی سراسری fetch (`setAllowUniversalAccessFromFileURLs`) فقط برای فراخوانی APIهای بازار از صفحه محلی لازم است. هیچ محتوای راه دوری داخل WebView بارگذاری نمی‌شود و تنها کد اجراشونده، assetهای خود برنامه است.

## 🔨 ساخت APK (بدون اندروید استودیو!)

این پروژه با ابزارهای متن‌باز و فقط از pypi / npm / GitHub ساخته می‌شود:

```bash
# ۱) دانلود ابزارها (~۹۰MB) — فقط یک بار
bash tools/fetch_toolchain.sh

# ۲) ساخت APK امضاشده
TOOLS_DIR=tools/toolchain bash tools/build_apk.sh

# خروجی: bin/cryptoscanner-1.0.0.apk
```

زنجیره ساخت: `aapt2` (منابع) → `javac از tools.jar` → `d8` (dex) → `apksigner` (امضای v1+v2+v3). کی‌استور خودکار ساخته می‌شود (`tools/toolchain/cryptoscanner.keystore`، رمز: `cryptoscanner123` — برای نصب جانبی).

### نصب روی گوشی
فایل `bin/*.apk` را به گوشی منتقل کنید و باز کنید. اگر «نصب از منابع ناشناس» غیرفعال است، اول آن را در تنظیمات فعال کنید. (نیازمند اندروید ۵ به بالا — خروجی arm64-v8a)

## 🔄 منابع داده و fallback

| نیاز | ترتیب تلاش (موازی) |
|---|---|
| کندل (OHLC) | بایننس ← بای‌بیت ← اوکی‌ایکس ← کراکن ← کریپتوکامپیر ← کوین‌گکو |
| فهرست بازار | کوین‌گکو ← کوین‌کپ ← بایننس |

اگر همه منابع قطع باشند، کش محلی (آخرین داده موفق) نمایش داده می‌شود.
