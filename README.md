# نبض کریپتو ۹.۰ — سیگنال قابل‌ارزیابی و چندتایم‌فریم

اپلیکیشن Native Android برای اسکن Spot/USDT، تشخیص حرکت غیرعادی و ارزیابی جهت‌دار با دادهٔ چندصرافی، تحلیل چندتایم‌فریم، دفتر سفارش، تشخیص رژیم و یادگیری ماشین روی دستگاه.

> ابزار آموزشی و paper tracking است؛ توصیهٔ مالی یا معامله‌گر خودکار نیست و هیچ سیگنال، درصد مدل یا نتیجهٔ گذشته تضمین سود نیست.

## تغییرهای اصلی نسخهٔ ۹

- **دفتر عملکرد واقعی سیگنال:** قیمت و زمان دقیق صدور، تأیید، TP1، TP2، ابطال و انقضا ثبت می‌شود. نتیجهٔ خالص پس از کارمزد و لغزش و مقدار `R` محاسبه می‌شود.
- **فرض محافظه‌کارانهٔ OHLC:** اگر STOP و هدف در یک کندل لمس شوند، STOP مقدم است. خروج مرحله‌ای نصف در TP1 و نصف در TP2/STOP ارزیابی می‌شود.
- **بدون سیگنال تکراری:** صدور مجدد فقط پس از محوشدن/تغییر جهت و cooldown ممکن است؛ سیگنال‌های فعال حتی اگر از فهرست برترین بازارها خارج شوند دوباره اسکن می‌شوند.
- **آمار تفکیکی:** نرخ نتیجهٔ مثبت، میانگین بازده خالص و میانگین `R` به تفکیک جهت، ارز و رژیم بازار داخل برنامه نمایش داده می‌شود.
- **زمینهٔ بزرگ‌تر:** روند ۱ساعته و ۴ساعته همراه با زمینهٔ BTC و ETH، جهت کوتاه‌مدت را تأیید یا مسدود می‌کند.
- **R:R پس از هزینه:** نسبت سود‌به‌ریسک ATR با کارمزد و لغزش ارزیابی می‌شود؛ طرح نامناسب عمداً به «صبر» تبدیل می‌شود.
- **Order Book فقط به‌عنوان گیت:** spread، عمق ±۰٫۵٪، عدم‌تعادل و لغزش سفارش فرضی ۱۰۰۰دلاری اندازه‌گیری می‌شود ولی به امتیاز جهت اضافه نمی‌شود.
- **تاریخچهٔ incremental:** cache خصوصی ۵دقیقه‌ای تا ۱۰ روز و برای منتخب‌ها تا ۳۰ روز نگه‌داری می‌شود؛ روندهای ۱ساعته/۴ساعته پوشش ۷/۳۰روزه دارند.
- **Calibration و drift:** مدل سه‌کلاسه با walk-forward و purge ارزیابی می‌شود؛ افت معتبر recall پنجرهٔ اخیر، کل رأی AI را تا بازیابی کیفیت غیرفعال می‌کند.
- **UI قابل‌ممیزی:** به‌جای امتیاز signed مبهم، «قدرت صعودی/نزولی x/100» و checklist گیت‌های برچسب قوی نمایش داده می‌شود.
- **اعلان ضداسپم:** اعلان اختیاری فقط برای صدور، تأیید، TP1، TP2، ابطال و انقضا است؛ تغییرهای هم‌زمان خلاصه و تکراری‌ها حذف می‌شوند.
- **نمودار کندلی تعاملی:** تا ۱۲۰ کندل OHLC با pinch-to-zoom، drag-to-pan، زمان صدور و خطوط frozen ورود/STOP/TP داخل برنامه نمایش داده می‌شود.

## تحلیل و منابع

- اجماع قیمت/حجم Binance، KuCoin، Bybit و OKX با حذف منبع پرت
- failover کندل و Order Book عمومی چهار صرافی
- اسکن ۴۰، ۸۰ یا ۱۲۰ بازار و افزودن نماد دلخواه/منتخب
- EMA ۹/۲۱/۵۰، RSI ۱۴، MACD، ATR، ADX و Median/MAD
- دو مدل softmax سه‌کلاسه برای افق‌های تقریبی ۱۵ و ۳۰ دقیقه، کاملاً روی گوشی
- بازکردن نماد انتخاب‌شده در TradingView و تولید Pine Script دقیق همان سطوح
- لینک‌های رسمی CoinMarketCap، CoinGecko و Google بدون اسکرپ صفحه

CoinMarketCap برای API رسمی کلید می‌خواهد و Google/TradingView فید عمومی مجاز برای بازتوزیع قیمت ندارند؛ بنابراین برنامه صفحهٔ رسمی نماد را باز می‌کند و دادهٔ محاسباتی را از API عمومی صرافی‌ها و CoinGecko می‌گیرد. Deep link عمومی TradingView اجازهٔ تزریق drawing ندارد؛ خطوط داخل برنامه خودکارند و Pine باید در Pine Editor جای‌گذاری شود.

## حریم خصوصی

ثبت‌نام، حساب صرافی، API key یا مجوز معامله لازم نیست. تاریخچه، دفتر paper، منتخب‌ها، تنظیمات و مدل روی فضای خصوصی گوشی می‌مانند. برنامه هیچ سفارشی ارسال نمی‌کند.

## ساخت و آزمون

```bash
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

APK نهایی و checksum:

```text
releases/NabzCrypto-9.0.0.apk
releases/NabzCrypto-9.0.0.apk.sha256
```

امضای نسخهٔ ۹ نسبت به ۸.۱ تغییر کرده است؛ برای نصب این build باید نسخهٔ قبلی را حذف کنید. حذف نسخهٔ قبلی، داده‌های محلی آن را نیز پاک می‌کند.

## معماری

- `analysis/OnDeviceAiAnalyzer`: ensemble سه‌کلاسه، walk-forward، calibration و drift gate
- `analysis/IndicatorEngine`: چندتایم‌فریم، R:R، نقدشوندگی، checklist و تصمیم نهایی
- `data/SignalJournal`: lifecycle و ارزیابی محافظه‌کارانهٔ paper
- `data/CandleHistoryStore`: cache incremental فشردهٔ ۱۰/۳۰روزه
- `data/`: چهار Provider، اجماع، failover، Order Book، cache و اعلان
- `ui/TradePlanChartView`: نمودار کندلی تعاملی و سطوح frozen
