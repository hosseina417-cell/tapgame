# نبض کریپتو ۸ — سیگنال سخت‌گیرانه با ensemble محلی

اپلیکیشن Native Android برای اسکن Spot/USDT، تشخیص حرکت غیرعادی و تولید ارزیابی جهت‌دار با ترکیب دادهٔ چندصرافی، تحلیل چندتایم‌فریم، تشخیص رژیم بازار و یادگیری ماشین روی دستگاه.

> ابزار آموزشی است، توصیهٔ مالی نیست و هیچ سیگنال، درصد مدل یا آزمون گذشته تضمین سود نیست.

## چرا سیگنال نسخهٔ ۸ بهتر و سخت‌گیرانه‌تر است؟

- **سه کلاس به‌جای حدس اجباری:** مدل می‌تواند «بالا»، «پایین» یا «خنثی» بگوید.
- **دو افق مستقل:** مدل‌های ۱۵ و ۳۰ دقیقه جداگانه آموزش می‌بینند؛ توافق دو افق رأی قوی‌تری دارد.
- **Walk-forward واقعی:** دو پنجرهٔ زمانی خارج‌نمونه، purge مرز و استانداردسازی فقط با گذشته.
- **برچسب تطبیقی:** حرکت کوچک‌تر از نویز اخیر به‌جای بالا/پایین، خنثی برچسب می‌خورد.
- **کالیبراسیون:** خروجی softmax با دادهٔ خارج‌نمونه temperature-calibrate می‌شود.
- **تشخیص رژیم:** ADX و ATR بازار رونددار، رنج، گذار یا بسیار پرنوسان را مشخص می‌کنند.
- **تأیید چندتایم‌فریم:** EMA و مومنتوم ۵ و ۱۵ دقیقه باید با جهت سازگار باشند.
- **گیت کیفیت داده:** تعداد منبع، spread، حجم، تعداد کندل و تازگی در امتیاز کیفیت دخیل‌اند.
- **امتناع هوشمند:** مخالفت AI، رژیم مخالف یا کیفیت پایین، سیگنال جهت‌دار را مسدود می‌کند.
- **قدرت محدود AI:** رأی مدل در `-12..+12` محدود است و هشدار پامپ/دامپ اولویت دارد.

نتیجهٔ این طراحی الزاماً سیگنال بیشتر نیست؛ هدف، حذف سیگنال‌های ضعیف و نمایش «صبر» در شرایط مبهم است.

## مدل روی دستگاه

برای هر بازار دو مدل softmax سه‌کلاسه از ابتدا روی حداکثر ۳۰۰ کندل بسته‌شده آموزش می‌بینند. ویژگی‌ها شامل بازده، فاصلهٔ روند، نوسان، حجم، بدنه، موقعیت کندل و کانال ۲۴ کندلی‌اند. آموزش و inference محلی است؛ کندل یا اطلاعات شخصی به سرویس AI ارسال نمی‌شود.

در جزئیات هر ارز موارد زیر نمایش داده می‌شود:

- احتمال مدل برای بالا، پایین و خنثی
- اعتبار فعلی و رأی محدود AI
- دقت متوازن walk-forward و تعداد نمونه‌های خارج‌نمونه
- توافق افق‌های ۱۵ و ۳۰ دقیقه
- رژیم بازار، ADX و کیفیت داده
- امتیاز تکنیکال جدا از امتیاز نهایی

## داده و امکانات

- تجمیع Binance، KuCoin، Bybit و OKX با حذف قیمت پرت
- رتبه و ارزش بازار اختیاری از CoinGecko
- اسکن ۴۰، ۸۰ یا ۱۲۰ بازار و افزودن نماد دلخواه
- failover کندل به سه صرافی
- EMA ۹/۲۱/۵۰، RSI ۱۴، MACD، ATR، ADX و Median/MAD
- TradingView با لمس کارت و لینک‌های رسمی CMC، CoinGecko و Google
- رابط فارسی RTL، cache محلی، بدون حساب، API key یا مجوز معامله

CoinMarketCap برای API رسمی به کلید اختصاصی نیاز دارد و Google و TradingView فید عمومی مجاز برای بازتوزیع قیمت ارائه نمی‌کنند؛ برنامه آن‌ها را اسکرپ نمی‌کند و صفحهٔ رسمی هر نماد را باز می‌کند. محاسبه از API عمومی چهار صرافی و CoinGecko انجام می‌شود.

## معماری

- `analysis/OnDeviceAiAnalyzer`: ensemble سه‌کلاسه، walk-forward و calibration
- `analysis/IndicatorEngine`: رژیم، ADX، گیت کیفیت و تصمیم نهایی
- `data/`: چهار Provider، اجماع، failover و cache نسخه‌دار
- `model/`: مدل‌های immutable بازار، AI، رژیم و نتیجه
- `ui/`: نمایش شفاف اجزای سیگنال و لینک‌های رسمی
