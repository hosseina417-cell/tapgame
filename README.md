# آربیتراژیار

برنامه Kivy برای پایش اختلاف قیمت تومانی رمزارزها بین صرافی‌های ایرانی:

- Nobitex
- Bitpin
- Wallex
- Ramzinex

این برنامه فقط از APIهای عمومی بازار استفاده می‌کند، کلید API نمی‌گیرد و سفارش‌گذاری خودکار انجام نمی‌دهد.

## اجرا

```bash
python main.py
```

## ساخت اندروید

```bash
buildozer android debug
```

## نکات ریسک

خروجی برنامه سیگنال قطعی معامله نیست. قبل از هر اقدام باید عمق سفارش، کارمزد سطح کاربری، هزینه و زمان انتقال شبکه، محدودیت برداشت/واریز و احتمال لغزش قیمت بررسی شود.
