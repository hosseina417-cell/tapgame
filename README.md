# نبض کریپتو ۵ — اسکنر اندرویدی بازار

اپلیکیشن Native Android برای اسکن بازارهای Spot/USDT، جمع‌بندی سیگنال‌های تکنیکال خرید/فروش و کشف **حرکت‌های پامپی/دامپی احتمالی**.

> این نرم‌افزار ابزار آموزشی است، توصیهٔ مالی نیست و معامله‌ای اجرا نمی‌کند.

## امکانات نسخهٔ نهایی

- اسکن هم‌زمان بازارهای پرنقدشوندهٔ USDT
- منبع عمومی با Failover خودکار: Binance Spot و KuCoin Spot
- تحلیل فقط روی کندل بسته‌شدهٔ ۵ و ۱۵ دقیقه
- EMA ۹/۲۱/۵۰، RSI ۱۴، MACD، ATR و تحلیل حجم
- تشخیص مقاوم ناهنجاری با Median/MAD و نسبت حجم به میانهٔ تاریخی
- جلوگیری از تبدیل جهش پامپی به سیگنال خرید تعقیبی
- برچسب‌های خرید قوی، خرید، صبر، فروش، فروش قوی، هشدار جهش و هشدار ریزش
- امتیاز «قدرت شواهد» (نه احتمال برد)
- جست‌وجو، فیلتر، منتخب‌ها، کش محلی و اسکن خودکار فقط در پیش‌زمینه
- رابط فارسی RTL با فونت Vazirmatn
- بدون حساب کاربری، کلید API، مجوز معامله یا ارسال دادهٔ شخصی

## ساخت APK

```bash
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

خروجی محلی:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Workflow دستی GitHub Actions بعد از تست و lint، APK نصب‌پذیر را با نام زیر تولید می‌کند:

```text
releases/NabzCrypto-5.0.0.apk
```

## معماری

- `data/`: HTTP امن، دو Provider، Failover، cache و تنظیمات
- `analysis/`: موتور قطعی اندیکاتورها و تشخیص ناهنجاری
- `model/`: مدل‌های immutable بازار و نتیجه
- `ui/`: تم، لیست بازار و Sparkline
- `MainActivity`: رابط Native بدون وابستگی UI خارجی

جزئیات پنج دور نقد و بازنویسی در `docs/CRITIQUE_LOOP.md` ثبت شده است.
