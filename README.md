# 🚗 دفترچهٔ ایرادات خودرو

اپلیکیشن اندرویدیِ **کاملاً آفلاین** برای ثبت و پیگیریِ ایرادهای خودرو،
با رابطِ فارسی و راست‌به‌چپ، تقویم شمسی و یادآوریِ سرویس دوره‌ای.

خروجیِ آمادهٔ نصب: [`dist/cardefect.apk`](dist/cardefect.apk) (۱۶۰ کیلوبایت، حداقل اندروید ۷ / API ۲۴)

---

## امکانات

| بخش | امکانات |
|---|---|
| **داشبورد** | تعداد ایرادهای باز، موارد بحرانی، برآورد هزینهٔ ایرادهای باز، سررسیدهای گذشته، فهرستِ «نیازمند توجه»، هشدارِ سرویس‌های عقب‌افتاده |
| **ایرادات** | ثبت/ویرایش/حذف، جستجوی فارسی (با یکسان‌سازی «ی/ك» عربی و ارقام)، فیلتر بر اساس خودرو/وضعیت/شدت، مرتب‌سازی (شدت، جدیدترین، سررسید، هزینه، کیلومتر)، **بازگردانی بعد از حذف** |
| **خودروها** | چند خودرو، پلاک/برند/مدل/سال، کیلومترشمار، بازهٔ سرویس، بایگانی، حذف با امکانِ بازگردانی |
| **سرویس** | وضعیتِ سرویس بر اساس **کیلومتر** و **زمان**، نوارِ پیشرفت، ثبت سرویس انجام‌شده |
| **داده‌ها** | پشتیبان‌گیری JSON، بازیابی (ادغام یا جایگزینی)، خروجی CSV برای اکسل، پاک‌سازیِ همهٔ داده‌ها |

جزئیاتِ فنی و کیفیت:
- داده‌ها فقط روی دستگاه ذخیره می‌شوند (localStorage)؛ **هیچ ارتباط شبکه‌ای وجود ندارد**.
- ذخیرهٔ نسخهٔ پشتیبانِ خودکار و بازیابیِ خودکار هنگام خرابیِ داده.
- مهاجرتِ خودکارِ داده از نسخه‌های قدیمی‌ترِ اسکیما.
- اعتبارسنجیِ ورودی با پیام‌های فارسی، محدودیتِ طول، پاک‌سازیِ کاراکترهای کنترلی.
- خروجی CSV در برابر تزریقِ فرمول (`=`, `+`, `-`, `@`) ایمن شده است.
- تاریخ‌ها شمسی و با ارقام فارسی؛ فونتِ وزیرمتن همراهِ برنامه است.
- ۳۱ تست خودکار (منطق + رابط).

## نصب روی گوشی

1. فایل `dist/cardefect.apk` را روی گوشی منتقل کنید (یا از بخشِ Release/Artifact همین ریپو بگیرید).
2. در اندروید، نصب از «منابع ناشناس» را برای مرورگر/مدیریت فایل مجاز کنید
   (`تنظیمات › اپلیکیشن‌ها › دسترسی ویژه › نصب اپلیکیشن‌های ناشناس`).
3. فایل را باز کنید و نصب را تأیید کنید.
4. چون برنامه امضای شخصی دارد، اندروید ممکن است یک‌بار هشدار بدهد؛ «نصب» را بزنید.

> حداقل اندرویدِ پشتیبانی‌شده: ۷/۰ (API ۲۴). برنامه هیچ مجوزی از کاربر نمی‌خواهد.


## اجرا و تست

```bash
# پیش‌نمایش در مرورگر (نسخهٔ وب)
python3 -m http.server 8000 --directory www

# تست‌ها
npm install          # فقط برای نصب jsdom (تست رابط)
npm test             # اجرای همهٔ تست‌ها
node tests/node/logic.test.js    # فقط منطق (بدون نیاز به وابستگی)
```

## ساخت APK

```bash
pip install cryptography       # فقط برای امضا
python3 tools/build_apk.py www dist/cardefect.apk
```

ساخت با ابزارهای مستقل قابل بررسی است:

```bash
aapt2 dump badging dist/cardefect.apk     # بررسی مانیفست و Activityِ قابل‌اجرا
openssl smime -verify -inform DER -in CERT.RSA -content CERT.SF -noverify  # بررسی امضا
```

نکته: خط لولهٔ `tools/` به‌جای Android SDK/Gradle نوشته شده چون در محیطِ توسعهٔ این
پروژه هیچ‌کدام در دسترس نبودند (و GitHub Actions هم مجوزِ اجرا نداشت).
برای انتشارِ رسمی، امضای v2/v3 با `apksigner` توصیه می‌شود.
