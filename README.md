# آربیتراژ تتر ایران 🇮🇷

اپلیکیشن موبایل (اندروید) برای مقایسه قیمت خرید/فروش **تتر (USDT/IRT)** در
صرافی‌های داخلی ایران و یافتن فرصت‌های **آربیتراژ بین‌صرافی‌ای** با احتساب
دقیق کارمزدها و کارمزد انتقال شبکه.

## ویژگی‌ها
- 📊 نمایش قیمت خرید/فروش تتر در صرافی‌های: نوبیتکس، والکس، بیت‌پین، اکسیر، رمزینکس، تترلند
- 💡 محاسبه بهترین فرصت آربیتراژ (بخر ارزان در A → بفروش گران در B)
- 💰 سود خالص پس از کسر: کارمزد خرید + کارمزد فروش + کارمزد انتقال تتر
- 🌐 مقایسه با نرخ دلار آزاد (tgju) و نمایش «حباب تتر»
- 🟡 حالت دمو (دیتای نمونه واقعی‌نما) برای تست بدون اینترنت
- ⚙ تنظیمات قابل ذخیره: مقدار معامله، کارمزد انتقال، حداقل حاشیه سود، خودکار
- 🔄 به‌روزرسانی خودکار ۳۰ ثانیه‌ای (بدون فریز شدن رابط)
- 🇮🇷 رابط فارسی با فونت Vazirmatn

## نحوه استفاده
۱. فایل `bin/*.apk` را روی گوشی اندروید نصب کنید (منابع ناشناس را فعال کنید).
۲. اجازه دسترسی به اینترنت را بدهید.
۳. دکمه «به‌روزرسانی» برای دریافت قیمت‌های زنده؛ یا از تنظیمات حالت دمو را روشن کنید.

## ساختار کد
- `arbitrage_core.py`: هسته مستقل (آداپتور صرافی‌ها، موتور آربیتراژ، کش) — بدون kivy
- `main.py`: رابط گرافیکی Kivy (موبایل)
- `buildozer.spec`: تنظیمات بسته‌بندی APK
- `.github/workflows/build.yml`: ساخت خودکار APK روی GitHub Actions

## ساخت محلی (اختیاری)
```bash
pip install buildozer kivy requests certifi
buildozer android debug
```

## نکته مهم درباره endpointها
آدرس‌های API صرافی‌ها در کد با پارس دفاعی چندفرمتی نوشته شده‌اند تا حتی با تغییر
جزئی ساختار پاسخ کار کنند. در صورت تغییر کلی API یک صرافی، کافی است تابع
پارس مربوطه در `arbitrage_core.py` را به‌روزرسانی کنید.
