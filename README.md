# نبض کریپتو ۶ — اسکنر چندمنبعی اندروید

اپلیکیشن Native Android برای اسکن بازارهای Spot/USDT، جمع‌بندی سیگنال‌های تکنیکال خرید/فروش و کشف **حرکت‌های پامپی/دامپی احتمالی**.

> ابزار آموزشی است، توصیهٔ مالی نیست و هیچ معامله‌ای اجرا نمی‌کند.

## قابلیت‌های نسخهٔ ۶

- پشتیبانی از صدها نماد USDT و تحلیل هم‌زمان ۴۰، ۸۰ یا ۱۲۰ بازار
- افزودن هر نماد دلخواه به اسکن و منتخب‌ها با گزینهٔ «＋ تحلیل»
- تجمیع تیکر از چهار صرافی عمومی: **Binance، KuCoin، Bybit و OKX**
- قیمت اجماعی مقاوم، حجم تجمیعی، حذف قیمت پرت و نمایش اختلاف منابع
- غنی‌سازی اختیاری رتبه و ارزش بازار با API عمومی **CoinGecko**
- انتخاب خودکار نقدشونده‌ترین صرافی برای کندل‌های ۵ و ۱۵ دقیقه
- EMA ۹/۲۱/۵۰، RSI ۱۴، MACD، ATR و ناهنجاری Median/MAD
- لمس کارت بازار برای بازکردن همان نماد در اپ/وب **TradingView**
- لینک مستقیم TradingView، CoinMarketCap، CoinGecko و Google در جزئیات هر ارز
- جست‌وجو، فیلتر، منتخب‌ها، cache محلی و اسکن خودکار فقط در پیش‌زمینه
- رابط فارسی RTL با فونت Vazirmatn
- بدون حساب، کلید API، مجوز معامله یا ارسال دادهٔ شخصی

## سیاست منابع

CoinMarketCap برای API رسمی به کلید اختصاصی نیاز دارد و Google و TradingView فید عمومی مجاز برای بازتوزیع قیمت ارائه نمی‌کنند. برنامه آن‌ها را اسکرپ نمی‌کند؛ دادهٔ محاسباتی را از APIهای عمومی چهار صرافی و CoinGecko می‌گیرد و صفحات رسمی سه سرویس دیگر را باز می‌کند.

## ساخت APK

```bash
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

خروجی نهایی این مخزن:

```text
releases/NabzCrypto-6.0.0.apk
```

## معماری

- `data/`: HTTP امن، چهار Provider، اجماع قیمت، failover، cache و تنظیمات
- `analysis/`: موتور اندیکاتورها و تشخیص ناهنجاری
- `model/`: مدل‌های immutable بازار و نتیجه
- `ui/`: تم، لیست بازار، Sparkline و لینک‌های خارجی امن
- `MainActivity`: رابط Native بدون وابستگی UI خارجی
